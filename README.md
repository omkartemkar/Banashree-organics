# Banashree Organics Website

A professional, fully responsive website for **Banashree Organics** — showcasing premium organic vermicompost products for sustainable agriculture.

---

## About the Project

Banashree Organics is based in Bengaluru, Karnataka. This website serves as their digital storefront and brand presence, featuring their vermicompost products, farm gallery, nutrient information, testimonials, and direct contact options.

---

## Features

- ✅ Fully responsive design (mobile, tablet, desktop)
- 🌿 Hero section with background animation and parallax effect
- 📦 Products section with WhatsApp enquiry integration
- 🧪 Nutrients & Benefits with animated counters
- 🖼️ Gallery with lightbox viewer
- 💬 Testimonials section
- 📞 Contact form with Google Maps integration
- 📱 Floating WhatsApp & Call buttons
- ❓ FAQ section
- ⚡ Smooth scroll animations throughout

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm v9 or higher

### Install Dependencies

```bash
npm install
```

### Run Locally (Development)

```bash
npm run dev
```

The site will be available at: **http://localhost:8080**

### Build for Production

```bash
npm run build
```

Output is generated in the `dist/` folder.

### Preview Production Build

```bash
npm run preview
```
